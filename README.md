# Public Data Scrapers

Ready-made scrapers for YouTube, app stores, news, newsletters, SEC filings, job boards, sports, e-commerce and Chinese platforms, with a Python example for each. Every scraper runs in the cloud on [Apify](https://apify.com/pipiagent): no proxies, no browser and no API keys of the scraped sites. Results come out as JSON, CSV or Excel.

## Quick start

1. Create a free [Apify account](https://console.apify.com/sign-up) and copy your API token from [Integrations](https://console.apify.com/settings/integrations).
2. `pip install apify-client` and set the `APIFY_TOKEN` environment variable.
3. Open the folder of the scraper you need, edit `input.json` and run `python example.py`.

Prefer clicking? Every scraper also runs from its Store page with a form, no code needed.
